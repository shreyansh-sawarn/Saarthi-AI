# Saarthi-AI

## Agentic Personal Banking Relationship Manager

Saarthi AI is an Agentic AI-powered personal banking relationship manager designed for the SBI Global Fintech Fest 2026 Innovation Challenge.

## Problem

Today's digital banking remains reactive. Customers receive generic notifications, limited financial guidance, and must initiate most interactions themselves.

## Solution

Saarthi AI transforms banking from reactive to proactive through a multi-agent AI architecture. Six specialized AI agents collaborate under a central AI Orchestrator to analyze customer behavior, identify financial opportunities, recommend personalized actions, and execute approved banking workflows securely.

## Key Features

- Finance Health Agent
- Product Recommendation Agent
- Digital Adoption Agent
- Engagement Agent
- Banking Assistant Agent
- Fraud Guardian Agent
